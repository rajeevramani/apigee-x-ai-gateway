# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues.

Report them privately through [GitHub private vulnerability reporting](https://github.com/rajeevramani/apigee-x-ai-gateway/security/advisories/new). Include the affected file, lab or reference, the skill version, and steps to reproduce. Leave out real credentials and project identifiers.

You should get an acknowledgement within 7 days.

## In scope

- Guidance or example policies that would expose backend credentials, API keys or prompts.
- Guidance that weakens caller authentication, quota, budget, Model Armor or burst enforcement.
- Setup steps that grant broader IAM access than documented.

Vulnerabilities in Apigee X, Model Armor, Vertex AI or the `apigee-x-proxy-development` dependency belong with those projects.

## Supported versions

Only the latest release receives fixes.
