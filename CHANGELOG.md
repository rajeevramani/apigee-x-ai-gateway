# Changelog

## 1.0.0 — First public release

- Agent skill for building AI gateways on Apigee X, with references and example policies for:
  - model routing with caller aliases and a runtime backend credential
  - accumulated token quotas sourced from the API product
  - cost budgets using API product prices and attributes
  - Model Armor prompt and response inspection
  - prompt-token burst protection with PromptTokenLimit
  - FAQ semantic caching as a disabled-by-default trial
- Evaluation labs 0–6 and a combined build, each with a prompt, deployment steps and smoke tests.
- Offline tests for example XML, flow order, policy pairing and the Model Armor validator.

See [feature status](references/capability-status.md) for how far each capability has been tested.
